# Dayoung’s Portfolio

UI/UX 디자인과 프론트엔드 개발 프로젝트를 소개하는 개인 포트폴리오입니다.
각 프로젝트의 기획 배경, 화면 설계, 주요 기능과 회고를 담았습니다.

[포트폴리오 보기 ↗](https://ekdudzkd.github.io/portfolio-2026/)

## 프로젝트

### 공구한
구매자와 판매자의 공동구매 경험을 한곳에서 연결하는 웹 서비스입니다. 상품 탐색부터 구매, 판매 관리까지 이어지는 화면과 사용자 흐름을 설계했습니다.

### Familink
AI 안부전화와 가족 소통을 연결하는 Android 앱입니다. 부모님은 편하게 일상을 이야기하고, 보호자는 리포트를 통해 안부를 확인할 수 있도록 역할별 화면을 구성했습니다.

### Blind Dating
사진 기반 AI 아바타와 취향 질문을 활용한 추천 서비스입니다. 스타일 선택, 스와이프 질문, 취향 기반 매칭과 채팅으로 이어지는 모바일 중심 경험을 설계했습니다.
