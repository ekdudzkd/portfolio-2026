01 / ABOUT

안녕하세요,
강다영입니다.

디자인을 전공하고, 웹 퍼블리셔·UI/UX 디자이너로 성장하기 위해 삼성청년 SW·AI 아카데미에서 코드를 배우며 다양한 프로젝트를 경험하고 있습니다. Adobe와 Figma를 활용한 디자인부터 와이어프레임, 프로토타입 제작까지 작업합니다.

Git으로 코드 변경 사항을 공유하고, 백엔드·AI 담당 팀원들과 API 연동과 화면 구현을 조율하며 협업했습니다.

Codex·Claude Code와 Jira·Figma의 MCP 연동을 활용해 자료 정리와 반복 업무를 자동화합니다. AI로 효율을 높이되, 결과를 직접 검토하고 최종 판단을 내려 작업물의 완성도를 지킵니다.

프로젝트를 통해 배운 내용을 실제 작업에 적용하고, 더 나은 화면을 만들기 위해 꾸준히 배우고 개선해 나가겠습니다.
