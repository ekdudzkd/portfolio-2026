01 / PROBLEM

어떤 문제에서 시작했나요?

  • 서로 다른 생활 패턴 때문에 부모님과 보호자가 자주 연락하기 어렵습니다.
  • 비슷한 질문이 반복되어 대화가 일상적인 안부 확인에 그치기 쉽습니다.
  • 부모님은 자신의 일상과 이야기를 누군가에게 전하고 싶어 합니다.
  • SNS와 디지털 서비스에 익숙하지 않은 사용자는 기존 가족 소통 서비스에 참여하기 어렵습니다.

02 / DESIGN DIRECTION

이야기가 가족의 대화로 이어지도록

보호자는 연락의 부담을 줄이면서 부모님의 일상을 확인하고, 부모님은 새로운 SNS 사용법을 배우지 않아도 편하게 이야기할 수 있어야 합니다. 안부 확인을 넘어 실제 가족 대화로 이어지는 소재를 만드는 데 초점을 맞췄습니다.

시간과 거리가 달라
자주 연락하기 어려워요.

AI 안부전화로
직접 연락하기 어려운 순간에도 이야기합니다.

떨어져 지내니
서로의 일상을 알기 어려워요.

가족 피드와 공유 캘린더로
서로의 근황과 일정을 공유합니다.

안부를 묻고 나면
어떤 이야기를 할지 막막해요.

통화 리포트로 부모님의 일상을 확인하고,
다음 대화의 소재를 만듭니다.

03 / SOLUTION & UI CHANGES

핵심 기능과 화면의 변화

AI 안부전화로 편하게 이야기하기

보호자와 연락하기 어려울 때에도 AI 전화로 일상을 이야기할 수 있도록 구성했습니다. 또한 AI 페르소나 음성의 자막을 제공하여 편리함을 높였습니다.

*실제 휴대폰 화면을 녹화한 자료입니다. (소리 포함)

대화 이후를 연결하는 리포트

전화 종료 후 대화 분석 리포트를 제공하고, 말투와 사용 단어를 바탕으로 감정 상태를 이모지로 표현합니다. 심부름이나 전달할 이야기는 별도 말풍선으로 구분해 빠르게 확인할 수 있도록 구성했습니다.

통화 상대를 고르는 페르소나

전화 시작 시 다양한 페르소나를 선택하는 재미 요소도 고려했습니다.

04 / MORE FEATURES

역할별로 다른 기능과 화면들

피보호자는 AI 안부전화, 보호자는 AI 리포트 기능을 이용하도록 역할별로 분기하여 설계했습니다.

실제 배포한 앱을 안드로이드 모바일 기기에 빌드하여 스크린샷을 캡쳐하였습니다.

회고

실제 기기에서 확인해야 보이는 문제

에뮬레이터로 확인하던 앱을 실제 갤럭시 기기에 빌드하면서 예상하지 못한 동선 문제를 발견했습니다. 앱 화면만 고려해 설계하다 보니, 기기의 뒤로가기 버튼을 눌렀을 때 이전 화면 대신 홈 화면으로 이동하는 문제가 있었습니다. 이를 수정하며 안드로이드 앱은 에뮬레이터뿐 아니라 실제 기기의 시스템 탐색 동작까지 검증해야 한다는 점을 배웠습니다.

모바일에서는 정보의 우선순위가 더 중요합니다

넓은 컴퓨터 화면에서 설계한 UI를 휴대폰으로 확인하니, 같은 글자 크기도 다르게 체감됐습니다. 좁고 긴 모바일 화면에서는 한 번에 보여줄 수 있는 정보가 제한됩니다. 여러 정보를 동시에 담기보다, 화면마다 핵심 기능과 정보에 집중할 수 있도록 우선순위를 정하는 것이 중요하다는 점을 배웠습니다.
